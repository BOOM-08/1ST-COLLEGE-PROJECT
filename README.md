# BHUMIT-VASAVA-S-PORTFOLIO

Modern, highly interactive 3D developer portfolio built with semantic HTML5, vanilla CSS, and JavaScript.

## 🚀 Key Features

* **3D Scroll Reveal & Mouse Tilt Effects**: Cinematic scroll animations and 3D card tilt tracking.
* **Interactive CLI Terminal**: Booting sequence terminal showing tech stack and status command.
* **Skills Tag Cloud & Bento Grid**: Grid layout presenting bio, interactive elements, and custom tag cloud.
* **Certifications (Section 06)**: Integrated credential module verifying Parul University OS, Google AI Studio, and Microsoft Learn achievements.
* **Resume Download**: Secure direct download of resume PDF.
* **Serverless Contact Form**: Fully verified client-side contact form with EmailJS integration and validation feedback.

## 🛠️ Tech Stack

* **Frontend**: HTML5, Vanilla CSS3 (Custom Variables), JavaScript (ES6)
* **API/Serverless**: EmailJS (Contact form)
* **Assets**: Unsplash images, custom vector SVG icons
